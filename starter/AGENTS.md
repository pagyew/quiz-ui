# Project rules

- Use Git and GitHub CLI. Keep `main` clean; work on `codex/…` branches.
- Do not read or write Mnemonik or any Tracker memory queue for this project.
- Keep quiz data in `site/answers.js`, game settings and copy in `site/game.config.js`, and branding overrides in `site/theme.css`.
- Use the installed `@pagyew/quiz-ui` package for shared UI and round logic.
- Run `npm run build` and play a round before submitting changes.
