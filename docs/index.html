03 / YOUR NEXT GAME

Bring the answers.
The rest is here.

Start with a working quiz. Change its data, words, colors, and rules. Build a static site and host it wherever you like. 

npx --registry=https://registry.npmjs.org/ @pagyew/quiz-ui init my-quiz
cd my-quiz
npm install
npm run dev

Node.js 22 or newer. The included project uses the public npm registry.
